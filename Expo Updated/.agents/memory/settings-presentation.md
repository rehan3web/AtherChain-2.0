---
name: Settings presentation
description: Repeated user requirements for the Settings profile and rows.
---

Keep the profile icon and overlapping pencil small. Do not show Invite & Earn or Get Help shortcuts on Settings. Omit row-side labels such as Unavailable and This device.

**Why:** The user repeated these removals after the larger profile, shortcuts and hints appeared again.

**How to apply:** Preserve these choices in future Settings redesigns. Keep accurate demo limitations in detail views without reintroducing the removed row hints.

Personal Information should open in the original compact bottom modal, not full-screen, and allow editing only the name, with a top cross icon and a single Save action. Do not show a username field or Cancel text.

**Why:** The user explicitly requested name-only editing and corrected the full-screen interpretation: they want the previous bottom modal.

**How to apply:** Keep the existing username unchanged when saving a name. The Settings profile header can still display the username.

Sessions is a separate full page with a back arrow, individual sign-out, and a log-out-all action, unlike the Personal Information bottom modal.

**Why:** The user explicitly asked for a new full Sessions page. Without account authentication, its actions can only manage a local demo list.

**How to apply:** Do not invent remote devices, locations or account logins. Keep sign-out honest about its demo scope until real authentication/session revocation is explicitly requested.

Do not show a theme-switch button in the dashboard header.

**Why:** The user explicitly requested its removal from the header.

**How to apply:** Keep theme selection in Settings Appearance; future header redesigns must not reintroduce the switch.
