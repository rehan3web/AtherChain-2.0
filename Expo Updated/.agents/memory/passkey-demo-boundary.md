Passkeys are a dummy flow like 2FA, not real device credentials or account authentication.

**Why:** The user explicitly chose “Dummy, 2FA jaisa” rather than real device passkeys.

**How to apply:** Keep onboarding consistent with 2FA/KYC. Creating a passkey adds an entry to the list; each specific entry can be deleted with a Sessions-style confirmation, and the bottom action adds a new passkey. Communicate the practice boundary without implying biometric verification or account protection.
